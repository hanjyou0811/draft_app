# Landing font

`dela-gothic-one-landing.ttf` is the Google Fonts text subset of **Dela Gothic One** for the landing title/actions and fixed room headings/actions (including Japanese labels, digits, and shaping glyphs). Dynamic topic, participant and candidate text uses the app's existing font stack.

Source: https://fonts.google.com/specimen/Dela+Gothic+One
Upstream: https://github.com/google/fonts/tree/main/ofl/delagothicone
License: SIL Open Font License 1.1; see `OFL-DelaGothicOne.txt`.

The subset is self-hosted so visitors do not need to connect to Google Fonts.
